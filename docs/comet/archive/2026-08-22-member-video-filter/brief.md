# Outcome

在用户空间（UP 主）页面的视频列表中提供客户端本地过滤器：一键隐藏播放量低于/超出阈值的视频，以及已观看（含已看完、看过未看完）的视频，帮助用户快速定位未看的高播放量内容。

# Scope

- 覆盖 `MemberVideo` 组件承载的全部 4 种列表：投稿视频（video）、充电专属视频、合集视频、系列视频。
- 过滤条件：
  - 播放量：最小播放量阈值 + 最大播放量阈值，均支持预设（1万/10万/50万/100万）与自定义输入，两侧均可关闭。
  - 已观看：两个独立开关「隐藏已看完」（history.progress == duration）与「隐藏看过未看完」（history 存在且未看完），可任意组合。
- 交互：
  - 列表头部（现有「共X视频/播放全部/排序」栏）新增筛选入口按钮，图标在有激活过滤时高亮。
  - 以底部弹窗展示过滤设置，风格对齐现有搜索页筛选弹窗。
  - 过滤仅作用于客户端已加载数据；开启过滤后当前页结果被滤空时自动加载下一页，直到出现符合项或列表到底，带频率限制防请求风暴。
  - 过滤开启且过滤结果非空时，滚到尾项仍可手动加载下一页（带节流），加载后重新过滤；不因���启过滤而丧失上拉加载能力。
  - 定位「上次观看」在过滤开启时基于过滤后列表计算目标位置；目标被当前过滤隐藏时走原回溯加载流程，不产生错位跳转。
  - 空数据态：无过滤空态维持原版「没有数据+点击重试」；有过滤空态区分「正在自动补载 loading」与「停止后提供调整过滤入口」；到底无符合项展示「没有更多了+调整过滤条件」。
- 识别依据：播放量取 `SpaceArchiveItem.stat.view`；已观看取 `SpaceArchiveItem.history`（progress/duration）。

# Non-goals

- 不做服务端过滤（空间 API 不支持此类参数）。
- 不做按标题关键词过滤（搜索页已有该能力，此处不重复）。
- 不改动 UP 主页其他 tab（动态、专栏、音频等）。
- 不持久化过滤设置到全局配置（每次进入页面重新设置；是否持久化留待后续反馈）。

# Acceptance examples

- A1: 投稿视频列表头部出现筛选入口；打开弹窗可设置最小播放量（如 10 万）后，列表中隐藏播放量低于阈值的视频，其余视频正常展示。
- A2: 弹窗中同时设置最大播放量阈值后，播放量超出上限的视频同样被隐藏。
- A3: 开启「隐藏已看完」后，角标为「已看完」的视频被隐藏；开启「隐藏看过未看完」后，有观看进度但未看完的视频被隐藏；两开关组合时对应视频均被隐藏；关闭全部过滤后列表恢复完整。
- A4: 合集、系列、充电专属三种列表与投稿列表行为一致，同一套过滤能力生效。
- A5: 开启过滤后当前已加载内容全部被滤空时，自动加载下一页直到出现符合项或到达列表末尾；连续加载有频率限制，不会触发请求风暴；到达末尾时向用户明确展示「没有更多了」而非空白。
- A6: 未开启任何过滤时，列表行为（加载、排序、定位上次观看等现有功能）与现状完全一致。
- A7: 过滤开启且过滤结果非空时，滚到尾项可手动加载下一页（带节流），加载后重新过滤，不丧失上拉加载能力。
- A8: 定位「上次观看」在过滤开启时基于过滤后列表定位，目标被过滤时走原回溯加载流程，不产生错位跳转。

# Constraints and invariants

- 不修改现有网络请求参数与接口调用逻辑（过滤纯客户端）。
- 过滤状态不得破坏 `MemberVideo` 现有功能：排序切换、播放全部、定位上次观看（fromViewAid/locate）、下拉刷新与上拉加载。
- 弹窗 UI 与项目现有筛选弹窗风格一致（Material 3、主题色、底部弹窗宽度约束）。
- 静态分析 `dart analyze`（或 `flutter analyze`）通过，无新增告警。
