## Android 杜比视界播放

杜比视界 Profile 5 默认使用软解和 `gpu-next` 渲染器，避免画面偏绿或偏紫。
检测依据为当前视频轨道，因此同样支持离线缓存的视频。Profile 8（包括 8.4）
和其他格式保持原有渲染方式及硬解偏好，切换视频后会恢复首选解码模式。

「音视频设置」中的「杜比视界 Profile 5 解码」仅提供软解兼容模式（mpv
`gpu-next`）和 Media3 原生播放。已移除实验性的 `mediacodec`、
`mediacodec-copy` Profile 5 选项，旧选择会按软解兼容模式处理。
其他格式的 mpv 硬解设置保持不变。修改模式后请关闭并重新打开视频。

软解模式通过 libplacebo 处理杜比视界，并非原生杜比视界显示直通。
播放信息中可查看 `hwdec=no`、`vo` 和杜比视界 Profile。
高分辨率 Profile 5 视频在软解时可能增加 CPU 占用或出现卡顿，
必要时可切换至非杜比画质。

### 实验性 Media3 原生模式

在同一设置中选择「Media3 原生播放器（实验性）」，然后重新打开视频。
此模式使用独立的 Android 全屏 Media3/ExoPlayer Activity 和 **SurfaceView**，
不经过 mpv 渲染或 Flutter 纹理。需要 Android 7.0+，以及声明支持杜比视界的
屏幕和解码器；不受 mpv「开启硬解」开关影响。默认仍为软解兼容模式。
播放画面与控件均延伸至刘海/挖孔区域，标题栏、进度条、底部控制栏和锁定按钮
不再额外预留安全边距；画面比例模式仍可能产生黑边。

明确标记 `dvhe.05`/`dvh1.05` 的视频直接使用 Media3；缺少编码元数据时
（包括离线缓存），由 mpv 检测当前轨道，识别 Profile 5 后先停止 mpv 再交接。
Profile 8.4、SDR、直播和仅播放音频仍使用 mpv。独立 DASH 音视频地址及请求头、
或本地音视频文件分别传入原生播放器，不使用 mpv 的 EDL 地址。

原生界面采用与 mpv 相近的布局：渐变背景的返回/标题栏、跟随主题颜色的缓冲
进度条、底部播放/时间/画面比例/倍速控制，以及侧边锁定按钮。
解码器信息移至「播放信息」，不再覆盖标题。倍速列表、快进快退步长、双击行为、
长按倍速和控制栏隐藏时长沿用现有播放器设置。单击显示/隐藏控制栏，
双击中间区域播放/暂停，双击两侧各四分之一区域快进快退（需开启快捷双击）。
长按画面临时加速，松手或离开播放器恢复原速度。锁定后禁用手势并锁定方向，
点击画面显示解锁按钮。原生画面比例仅作用于本次原生播放。

返回时将位置和倍速交回 PiliPlus，
不会自动恢复 mpv；点击播放可从该位置再次打开 Media3。播放完成沿用现有循环/
下一集策略。切到后台会停止播放，回到原生播放器后需手动继续。
此模式不支持弹幕、外挂字幕、mpv 滤镜、SponsorBlock 跳过、后台播放和画中画。
此界面仍为原生控件，未复用 Flutter/mpv 的滑动亮度/音量/进度手势、
进度缩略图、自定义底部按钮顺序及播放器内画质/选集功能。
原生播放错误会明确提示，不会静默切换至普通 HEVC 解码或 mpv。

设备测试时请与软解模式对比同一个 Profile 5 视频，点击「播放信息」查看实际
解码器名称及 `SurfaceView` 信息，检查颜色、系统杜比视界标识、音画同步、
拖动/续播、旋转、返回和前后台切换，然后确认 Profile 8.4 播放未受影响。
能力检查不代表所有设备都能正确输出杜比视界；失败或颜色异常时请切回软解并重新打开视频。
