## 可选播放与直播增强

本节对应的新增及修改代码由 **OpenAI Codex 编写**，功能需求由提交者提出，并由提交者提供 macOS 使用反馈。原项目代码及作者归属保持不变。以下为客户端实现范围，不将界面入口等同于真实交易已完成。

| 功能 | 使用方式与已实现内容 |
| --- | --- |
| 自动选择 CDN | 实验性开关默认关闭，按当前视频有效供给选择来源，优先尝试华为并有界尝试备源。与并发分开设置；开启自动选源后暂停手选 CDN，关闭后恢复 |
| 点播并发 | 实验性开关默认关闭，支持 DASH 视频和音频。自适应默认开启，健康流连续接收，供给不足时调整分块窗口，最多 8 路；手动模式可设置 1–32 路和 64–4096 KiB |
| 低速与中断恢复 | 取消慢请求及时释放连接名额；区分播放器输出等待与上游低速；按尚未交付字节恢复。切源维持 Range、总长、各源版本、样本和会话校验；仅自动选源的视频低速恢复要求自适应开启 |
| CDN 测速 | 显示连续分段均速、最慢段及首包等待；播放器入口可以当前视频抽样，设置页仍使用固定样片，结果不保证后续速度 |
| 直播增强布局 | 默认关闭，独立于 CDN 和画质。弹幕输入固定在聊天区下方；粉丝团/勋章在输入左侧，点赞/表情/SC 在上方右侧；视频下方最右礼物按钮展开快捷条，快捷条最左上箭头打开完整菜单 |
| 礼物与粉丝互动 | 礼物/背包目录、价格、库存、数量和提交确认；粉丝状态、勋章、亲密度与任务；普通赠礼、入团、灯牌、勋章佩戴/摘下分别处理并核对服务端状态。确认绑定账号和房间，重复点击不重复提交，未知结果不自动重发 |
| 电池价格 | 付费礼物价格及余额按 100 原始 gold = 1 电池精确显示，请求仍使用服务端原始单位；银瓜子保持自身单位 |
| SC 与直播连接 | 历史/实时 SC 合并、去重、删除和过期；连接/认证超时、心跳、有界重连及房间/账号会话隔离；这些正确性改动在增强关闭时也生效 |
| 官方页面 | 应用内承载官方充值、大航海和 SC 直播间页面，进入前保护当前网页登录身份。载入或返回页面不表示购买、充值或开通成功 |
| 应用内小窗 | 默认关闭，区别于系统 PiP。退出观看到非播放页面时承接原会话，暂停退出仍保持暂停；支持播放/暂停、关闭、还原、拖动及缩放。切换相关视频、列表或队列项目不建立旧视频小窗 |
| 临时播放列表 | 默认开启，独立于云端稍后再看。下一条/队尾加入、同视频及分 P 去重移动、拖动排序、顺序连播、跨重启按游客/账号保存；列表/收藏夹批量入队，整队加入已有或新建收藏夹，分页进度、取消及部分失败提示 |
| 账号和网页会话 | 账号变化前关闭绑定的小窗/官方页面，串行清理与同步网页登录态，旧回调不覆盖新账号；账号对象和会话代次参与异步结果校验 |

当前边界：

- 自动 CDN 不接管直播流或独立听音频页面；启用系统代理时旁路。签名过期自动刷新、完整播放期限/VBR 调度和应用内诊断导出尚未完成。
- 普通赠礼、入团、点亮和批量收藏的客户端代码已接线，但真实账号写操作及最终结果尚未完整验收。原生 SC 购买/审核/订单、大航海开通/续订和完整支付结果查证尚未完成；公告、PK、多人互动和抽奖活动不属于已完成范围。
- 官方付费页在 macOS/iOS 只清理 Bilibili 域 Cookie；Android/Windows 会清理全部 WebView Cookie，可能使其他内嵌网页退出登录；Linux 因不能可靠核对 HttpOnly 身份而阻止打开这些付费页。
- macOS 已有部分构建、游客界面及实际使用反馈，用户反馈最新版暂未见卡顿。其他平台、真实交易、默认小缓存、长期播放及硬件解码仍需进一步验收，不宣称所有网络均改善或与官方直播观看端功能等量。
