# 作者专属倍速设计

## 背景

当前客户端只有全局默认倍速（`Pref.playSpeedDefault`）与长按倍速。用户对部分 UP 主习惯用固定倍速观看（例如教程向 UP 用 1.25x、节奏慢的 UP 用 2.0x），却只能在每个视频里手动切换，体验割裂。

项目内已有可复用基础：

- 倍速设置页：`lib/pages/setting/pages/play_speed_set.dart`
- 播放器倍速：`PlPlayerController`（`setPlaybackSpeed` / `setDefaultSpeed`）
- 按 UID 管理用户：`getListUidWithNameModel`（屏蔽用户 / 白名单）
- 用户搜索：搜索面板 `search_panel/user`
- UGC 作者信息：视频详情 `owner.mid`

## 目标

- 可为指定视频作者设置独立的默认开播倍速
- 未指定作者的视频继续使用全局默认倍速
- 在设置页方便地添加作者：支持昵称搜索与直接输入 UID
- 每个作者各自一个倍速（非全名单共用一个值）
- 播放中手动改速仅对当前会话生效，不回写作者规则

## 非目标

- 播放页 / 个人主页快捷添加入口
- 关注列表批量导入
- 番剧（PGC）/ 音频 / 直播套用本规则
- 作者专属长按倍速
- 云同步、远程配置
- 列表展示头像（可后续增强）
- 设置页修改规则后热更新当前正在播放的会话

## 方案选择

### 方案 A：扩展现有「倍速设置」页（采用）

在 `倍速设置` 页底部增加「作者专属倍速」区块；存储 `mid → {name, speed}`；UGC 开播时按 `owner.mid` 解析有效默认倍速。

优点：

- 与现有倍速配置同路径，发现成本低
- 复用倍速列表、UID 管理、用户搜索能力
- 改动面集中，易测

缺点：

- 倍速设置页变长

### 方案 B：独立「作者倍速」设置页

播放设置新增入口，单独页面管理。

优点：职责独立，便于后续扩展

缺点：多一层导航；与默认倍速/倍速列表割裂

### 方案 C：通用播放参数规则引擎

抽象「按条件覆盖播放参数」，作者倍速作为首条规则。

优点：扩展性强

缺点：当前需求用不上，违反 YAGNI

**结论：采用方案 A。**

## 数据模型

```text
AuthorPlaySpeed {
  mid: int       // UP 主 UID，主键
  name: String   // 展示名
  speed: double  // 该作者专属倍速
}
```

### 存储

- 位置：与现有倍速配置一致，使用 `GStorage.video`（或同等本地 Hive box）
- Key：新增 `VideoBoxKey.authorPlaySpeeds`（名称以实现时 `storage_key.dart` 为准）
- 形态：可序列化的 `Map` / `List<Map>`，内存侧统一为 `Map<int, AuthorPlaySpeed>`

### 读取 API（概念）

```text
Pref.authorPlaySpeeds
  → Map<int, AuthorPlaySpeed>

Pref.playSpeedForAuthor(int? mid)
  → mid 命中则返回作者 speed
  → 否则返回 Pref.playSpeedDefault
```

### 约束

- 同一 `mid` 仅一条；再次添加则更新 `name` / `speed`
- 名单中的 `speed` 按数值生效，不要求该值仍存在于 `speedList`
- 不覆盖、不修改全局默认倍速与长按倍速配置
- `name`：搜索添加时写入接口返回昵称；纯 UID 添加时尽量解析昵称，失败则 `UID:<mid>`

## 设置页交互

### 入口

播放设置 → **倍速设置**（现有路由 `/playSpeedSet`）

页面结构（自上而下）：

1. 默认倍速 / 动态长按倍速 / 默认长按倍速（现有）
2. 倍速列表（现有）
3. **作者专属倍速**（新增）

### 作者专属倍速区块

```text
作者专属倍速                         [添加]
指定 UP 主的视频以专属倍速开播；未列出的作者
使用上方默认倍速。播放中手动改速仅本次有效。
────────────────────────────────────────
昵称 (UID)                      1.5x   ⋯
昵称 (UID)                      2.0x   ⋯
```

空态文案示例：「尚未添加作者，点击添加」。

### 添加流程

点击 **添加**：

1. **选人**（同页支持两种方式）
   - 搜索：输入昵称/关键词 → 调用现有用户搜索能力 → 结果列表点选（展示昵称 + UID；头像可选）
   - UID：数字输入 → 确认后解析用户信息（有接口则取昵称，失败则 `UID:<mid>`）
   - 若 mid 已在名单中：提示将更新倍速，并带出当前配置

2. **选倍速**
   - 从当前 `Pref.speedList` 选择
   - 第一版不支持在此流程内自定义新倍速数值（避免与倍速列表维护分叉）；若需要新数值，先在上方「倍速列表」添加

3. **保存** → 列表即时刷新

### 列表管理

- 点行或倍速标签：修改该作者倍速（同样从 `speedList` 选择）
- 删除：滑动删除或菜单删除；删除后该作者回退全局默认
- 不提供单独的「改昵称」编辑；以添加/搜索时写入为准

## 播放生效逻辑

### 解析规则

```text
effectiveDefaultSpeed(mid) =
  authorPlaySpeeds[mid]?.speed  ??  Pref.playSpeedDefault
```

仅对 **UGC 视频** 生效。

### 应用时机

- UGC 详情页拿到 `owner.mid` 后、真正设定播放器 rate / 自动播放前，应用一次 `effectiveDefaultSpeed`
- 切换分 P / 合集内视频时：
  - 同一作者：重新套用该作者 effective 默认
  - 不同作者：按新 mid 重新解析
- 非 UGC、或 mid 为空：使用全局默认倍速，行为与改前一致

### 与现有播放器 API 的关系

| 能力 | 行为 |
| --- | --- |
| 开播默认倍速 | 使用 `effectiveDefaultSpeed(owner.mid)` |
| `setPlaybackSpeed`（用户手动选速） | 仅改当前会话，不写 Pref，不写作者名单 |
| `setDefaultSpeed` / temp 重置 | 回到**当前视频**的 effective 默认，而非无脑全局默认 |
| 长按倍速 | 保持现有逻辑（动态双倍或全局长按默认） |
| 设置页改规则时正在播放 | 当前会话可不热更新；下次开播生效 |

### 边界情况

| 场景 | 行为 |
| --- | --- |
| 作者规则被删，正在播其视频 | 当前会话不强制改；下次开播用全局默认 |
| 全局默认变更，作者有专属 | 专属优先，不受影响 |
| 作者 speed 已不在 speedList | 仍按名单中的数值生效 |
| 手动改速后再切到同作者另一集 | 重套该作者 effective 默认 |
| 番剧 / 音频 / 直播 | 不走本功能 |

## 实现落点（指导，非逐步任务）

预期主要改动面：

1. `lib/utils/storage_key.dart` / `storage_pref.dart`：存储 key 与读写 API
2. `lib/pages/setting/pages/play_speed_set.dart`：作者列表 UI 与添加/编辑/删除
3. 用户搜索/UID 解析：复用 `search_panel/user` 或 `http` 现有用户接口
4. `lib/plugin/pl_player/controller.dart`：默认倍速解析与 `setDefaultSpeed` 语义
5. UGC 视频页 / introduction controller：在已知 `owner.mid` 时注入 effective 默认

具体实现步骤与测试清单由后续 implementation plan 展开。

## 测试与验收

### 功能验收

1. 设置作者 A = 1.5x、全局默认 1.0x → 打开 A 的 UGC 视频自动 1.5x
2. 打开未配置作者 B 的 UGC 视频 → 1.0x
3. 在 A 的视频内手动改为 2.0x → 仅本次；退出再进仍 1.5x
4. 设置页可用昵称搜索添加作者
5. 设置页可用 UID 添加作者（解析失败时显示 `UID:<mid>`）
6. 可修改已有作者倍速、可删除规则
7. 删除 A 后再次打开 A 的视频 → 回退全局默认
8. 非 UGC（如番剧）行为与改前一致

### 回归关注

- 全局默认倍速 / 长按倍速 / 倍速列表增删
- 播放器手动切换倍速、弹幕速度联动
- tempPlayerConf 下的设置重置行为
- 分 P / 合集切换时的倍速表现

## 风险与决策

| 风险 | 处理 |
| --- | --- |
| 用户搜索接口差异 / 需登录 | 搜索失败时仍可用 UID 添加，并 toast 明确错误 |
| 播放器单例跨视频残留倍速 | 切视频时强制按新 mid 重算 effective 默认 |
| 倍速设置页过长 | 第一版可接受；若后续膨胀再拆页 |
| 与上游合并冲突 | 改动集中在 fork 倍速设置与播放器默认速解析，冲突面可控 |
